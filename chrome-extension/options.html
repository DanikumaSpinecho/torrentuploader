Liaison avec l'application

Vérification…
  1. Lancez l'application Torrent Uploader.
  2. Cliquez sur Intégration, puis sur Activer.
  3. C'est tout : l'extension trouve l'application, et la lance si elle est fermée.

Comportement

Connexion manuelle (avancé)

À n'utiliser que si la liaison automatique est impossible sur ce poste. L'application doit alors être ouverte pour recevoir les envois. Les deux valeurs se trouvent dans l'application : Intégration → Connexion manuelle.
