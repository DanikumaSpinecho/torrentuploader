Send `.torrent` files and magnet links to a ruTorrent / rTorrent seedbox. *Version française ci-dessous.*

| File | What it is |
|---|---|
| `TorrentUploader.exe` | The application — standalone, **no Python needed**. Put it in a folder of its own and double-click it. |
| `TorrentUploader-Extension-*.zip` | Chrome / Edge extension: unzip, then `chrome://extensions` → Developer mode → Load unpacked. |
| `Notice-Torrent-Uploader-*.pdf` | User manual (French). |
| `TorrentUploader-*-complet.zip` | Everything: executable, Python version, extension, manual. |

Getting started: run the app, enter your seedbox, then **Intégration → Activer**. See the
[README](https://github.com/DanikumaSpinecho/torrentuploader#readme) for details.
